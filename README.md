A full-stack Job Portal web application that connects job seekers and employers on a single platform.

The application allows job seekers to create accounts, build professional profiles, search for suitable job opportunities, and apply for jobs. Employers and companies can create accounts, manage company information, post job vacancies, and manage applications from potential candidates.

The project is built using a modern React + TypeScript frontend, Node.js + Express backend, and MongoDB database, with Tailwind CSS used for responsive user interface design.
